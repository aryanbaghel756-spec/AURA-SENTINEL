# 🧠 PART 3: ANTICIPATED JUDGES' QUESTIONS & WINNING REPLIES

### Q1: *"Why use Blockchain? Isn't a database with backups enough?"*
> **Answer:** *"Sir, database backups are controlled by the system administrator. If the administrator's credentials are stolen via spear-phishing, or if an insider is bribed, they can delete database backups and alter SQL tables.  
> Our Blockchain ledger calculates SHA-256 Merkle roots of transaction data where each block header contains the cryptographic hash of the previous block. Modifying even 1 rupee in historical loss invalidates every subsequent block and breaks consensus across the AICTE consortium nodes. It provides mathematical non-repudiation required by CERT-In and judicial audit courts."*

### Q2: *"How accurate is your Financial Risk Quantification in ₹ INR?"*
> **Answer:** *"We strictly follow the **Open FAIR Model (ANSI/FAIR)**, which is the international standard for cyber risk economics. Rather than guessing, we take:  
> 1. Real-time external attack surface (listening socket count),  
> 2. Endpoint compute saturation (memory & CPU stress indicators),  
> 3. Asset valuation inputted by the institution.  
> We then calculate operational downtime cost per hour calibrated against Indian enterprise average outage metrics."*

### Q3: *"Can the Hand Gesture and Computer Vision run on ordinary college PCs without costly GPUs?"*
> **Answer:** *"Yes, sir! We specifically selected **YOLOv8 Nano (yolov8n.pt)** running ONNX-optimized CPU inference and **MediaPipe Hand Landmarker** running at <30ms latency on standard Intel i3/i5 CPUs without requiring expensive NVIDIA GPUs. Everything runs local-first with zero cloud API costs."*

Evaluators can see exactly how data moves through AURA Sentinel in 5 logical, mathematically defensible stages.

01 INGEST

Telemetry Ingestion

Agentless connection to enterprise networks, OS metrics (CPU/RAM/Ports), cloud infrastructure (AWS/Azure), and live CVE vulnerability feeds.

Inputs:
• Open Ports & Services
• CVE / CVSS / EPSS Scores
• Critical Asset Valuation
Zero-Agent API ➔ Next
02 FAIR MODEL

Actuarial Translation

Converts raw technical vulnerabilities into financial risk parameters using Open Group FAIR: Loss Event Frequency (LEF) and Loss Magnitude (LM).

FAIR Formula:
Risk = LEF × LM
Downtime + Recovery + Data Impact + System Value
₹ Monetary Loss ➔ Next
03 SIMULATE

Monte Carlo (10k)

Runs 10,000 lognormal stochastic paths in NumPy in <850ms to generate empirical Loss Exceedance Curves and the 95% Value-at-Risk (₹ VaR).

Probability Dist:
• 95th Percentile VaR
• Expected Annual Loss (ALE)
• Worst-Case Scenarios
Loss Curve ➔ Next
04 OPTIMIZE

Knapsack Optimizer

Solves the 0/1 Knapsack Dynamic Programming problem: Given a budget limit, finds the exact subset of defensive controls that yields maximum risk reduction ROI.

Mathematical Goal:
Maximize ∑(Risk Reduction)
Subject to ∑(Cost) ≤ Budget
Optimal Spend ➔ Next
05 AUDIT

Merkle Blockchain

Every risk score, timestamp, and audit event is cryptographically sealed into a SHA-256 Merkle Hash Tree for immutable compliance with DPDP & CERT-In.

Zero-Trust Trust:
• Tamper-evident blocks
• Non-repudiable audit logs
• Instant cryptographic proof
Board Console ✓ Complete
